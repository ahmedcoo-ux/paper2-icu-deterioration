# ICU deterioration prediction beyond the NEWS-2 score (MIMIC-IV)

Code for the paper *[title as submitted]* (Ahmed J. Jabur, 2026).

The study predicts deterioration in adult ICU patients, defined as a six-component NEWS-2 score of 7 or more within
the next 6 hours, from 5-hour windows of routinely charted data in MIMIC-IV v3.1, and asks whether a gradient-boosted
model adds information beyond the score itself, including among patients with the same NEWS-2 value.

## Data access
This repository contains **code only**. MIMIC-IV v3.1 is available to credentialed users from PhysioNet
(https://physionet.org/content/mimiciv/3.1/, DOI 10.13026/kpb9-mt58) after completing the required training and
signing the data use agreement. Under that agreement no patient-level data, derived features, labels or predictions
are shared here; all of them are regenerated by running the code.

Main steps:
1. **Cohort** of adult ICU stays (81,916 stays, 58,559 patients) (`01_cohort.py`).
2. **Hourly signals**: vital signs (`02_hourly_signals.py`), GCS and AVPU proxy (`02b_gcs_avpu.py`) and 16 laboratory
   values (`03_labs.py`) on an hourly grid.
3. **Windows**: 5-hour observation windows with a 6-hour prediction horizon (3,498,146 windows); label = NEWS-2
   (six components) >= 7 within the horizon, with component-specific carry-forward limits (consciousness 48 h, heart
   rate 8 h, other components 4 h); windows already at NEWS-2 >= 5 are excluded.
4. **Features**: 223 window features, rebuilt leak-free (`09_corrected_inputs_v6_2.py`).
5. **Temporal split** into development and held-out periods; 5-fold patient-grouped cross-validation on development.
6. **Models**: LightGBM (300 trees, learning rate 0.05, 63 leaves), Platt calibration on out-of-fold predictions.
7. **Evaluation** on the held-out set (658,615 windows): AUROC, AUPRC, within-NEWS-2-score AUROC, calibration;
   patient-level paired bootstrap (2,000 resamples); NEWS-2-inputs baseline; tables and figures.
8. **Clinically independent outcome** (organ support: vasopressor start or mechanical ventilation), labels built by
   `pipeline/10_organ_support_labels.py` (shared with a separate study on the same MIMIC-IV windows).

## Setup
1. Install Python and the packages in `requirements.txt` (`pip install -r requirements.txt`).
2. Download MIMIC-IV v3.1 from PhysioNet.
3. Put this repository's folder on your Python path (the scripts import the `paths` package) and set `<PHD_ROOT>`
   in `paths/shared.py` (and `<HOME>` where it appears in the scripts) to your own folders.
4. Run the files in `pipeline/` in numeric order, then `analysis/`.
